# web — 前端

設計（風格、畫面、動畫）見 `docs/frontend-design.md`。

## 農民手機頁 `farmer.html`

接後端的正式頁面。先啟動後端（`.venv\Scripts\python -m uvicorn app.main:app --port 8001`），
用 `POST /api/cases` 建立案例，再用回傳的 `farmer_token` 開啟：

```text
http://localhost:8001/web/farmer.html#t=<farmer_token>
```

流程：拍謄本 → 收到了（自動等擷取完成）→ 回答 3 題（可聽可講）→ 完成。重新打開連結會停在原處。
朗讀用 `audio/manifest.json` 對應的音檔，沒有音檔就用瀏覽器語音；語音功能在 `voice.js`。

## 測試台 `prototype.html`

不需要後端就能跑完整流程的前端原型，用假謄本（`data/samples/fake-transcripts/`）測試介面與 agent 流程。

### 開啟

```bash
python -m http.server 8000
```

在專案資料夾執行上面的指令，再打開 http://localhost:8000/web/prototype.html。
直接雙擊檔案開啟時，瀏覽器不允許讀取資料。

### 三個畫面

| 畫面 | 內容 |
| --- | --- |
| 農民手機 | 拍謄本 → 收到了 → 回答 3 題（可聽可講）→ 完成。依高齡友善規則：大字、大按鈕、一頁一題 |
| 協助者核對 | AI 擷取的欄位對照謄本圖片，逐欄確認／修正／退回；填公頃面積、實施期間、耕作人 |
| 同意書預覽 | 依紙本版面預覽；還有未確認欄位就標「草稿」並列出原因 |

### 測試控制台（右側）

- **模擬拍照**：用清楚的測試照片，或故意用又暗又糊的照片，測試 ① 收件 agent 會不會退件。照片檢查真的會計算亮度與清晰度（門檻：亮度 ≥ 90、清晰度 ≥ 250，依真實照片校正）。
- **模擬語音輸入**：沒有麥克風或瀏覽器不支援時，打字代替「聽到的話」，可以測國語和台語關鍵詞（例如「毋是」「予人種」「稅予人」）。
- **朗讀（Qwen3 TTS）**：切換國語／台語。有 `web/audio/` 音檔就播音檔，沒有就用瀏覽器內建語音。
- **模擬 AI 讀錯**：故意讓擷取結果的一個面積錯掉，測協助者能不能對照圖片抓出來。
- **agent 紀錄、任務清單**：看每個背景 agent 做了什麼。

### 建議測試情境

1. **C03 壞照片**：按「用壞照片」，應該被退回並唸出「照片有點暗」。
2. **語音聽不懂**：在問題畫面送出「今天天氣很好」兩次，第二次應該請你改按按鈕。
3. **台語回答**：送出「毋是」，應該唸回「你講，不是，對嗎？」。
4. **C03 陷阱**：協助者畫面應該標出「另一筆土地有相同地號」與「看不清」。
5. **正式版關卡**：欄位沒全部確認、公頃面積沒填時，同意書只能是「草稿」。

### 語音音檔（OpenAI TTS）

句子清單在 `audio/prompts.json`（`python tools/collect_prompts.py` 從程式收集），
用 `python tools/gen_tts.py --engine openai --lang zh --missing` 產生 mp3（需要 `.env` 裡的 `OPENAI_API_KEY`，一句約 2 秒）。
網頁依 `audio/manifest.json` 對照文字播放；找不到音檔才用瀏覽器內建語音。
注意事項見 `docs/voice-design.md` 第 5 節。

### 限制

- 手機上要用 HTTPS 才能使用麥克風；在筆電用 `localhost` 開啟則可以。
- 這是原型：資料只存在瀏覽器記憶體，重新整理就會清空。
