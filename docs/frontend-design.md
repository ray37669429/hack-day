# 前端設計

> 狀態：已定案（2026-11-07）。延續 [farmer-ux-agents.md](farmer-ux-agents.md)、[voice-design.md](voice-design.md)、[backend-design.md](backend-design.md)。

## 1. 頁面

| 檔案 | 誰用 | 說明 |
| --- | --- | --- |
| `web/farmer.html` | 農民（手機） | 開啟網址 `/web/farmer.html#t=<token>`，全部資料走 `/api/f/{token}` |
| `web/helper.html` | 協助者（筆電） | 建立案例、核對、填人工欄位、產生同意書（下一步做） |
| `web/voice.js` | 農民頁 | 朗讀（先播 `web/audio/` 音檔，沒有才用瀏覽器語音）、收音、關鍵詞比對 |
| `web/prototype.html` | 測試、展示備案 | 不需要後端的離線測試台，不再改 |

純 HTML + JS，不用打包工具，FastAPI 直接提供檔案。

## 2. 視覺風格：參考多鄰國的手法，為高齡農民調整

**學它的**

- **厚底立體按鈕**：底部 5px 深色邊，按下去往下沉。一看就知道能按，按了有手感。
- **頂部粗進度條**：比小圓點容易看出「快好了」。
- **底部回饋面板**：答完從下面升起「記好了：是」＋「繼續」。回饋固定在同一位置，主要按鈕在拇指按得到的地方。
- **大圖示選項卡片**：第 3 題四種耕作方式做成 2×2 卡片。和第 1、2 題一樣點一下就送出，按錯可以按面板上的「不對，重選」。
- **角色用對話框問問題**：配合語音，點對話框就再唸一次。
- 圓角、飽和但不刺眼的顏色。

**刻意不學的**

- 連續天數、愛心扣命、經驗值、排行榜、計時：這不是考試。
- 紅色「答錯了」：每個答案都有效，「不是」「我不確定」也一樣是綠色的「記好了」。
- 大量彩帶、吵的音效：只在最後做一次溫和的慶祝。
- 多鄰國的品牌（貓頭鷹、招牌綠、專屬字型）一律不用。

**顏色**（固定淺色，戶外陽光下看得清楚；不做深色模式）

| 用途 | 顏色 |
| --- | --- |
| 底色 | 米白 `#FFFDF7` |
| 文字 | 深褐 `#2B2118`；次要 `#5C4A36` |
| 主要按鈕、完成 | 稻綠 `#4A9A2E`，底邊 `#357322` |
| 選中、回饋面板 | 淺綠 `#DDF0D0`，字 `#27500A` |
| 提醒（照片太暗） | 琥珀底 `#FAEEDA`，字 `#854F0B` |
| 框線 | `#DCD2BE` |

不用紅色。

**角色「斗笠阿伯」**：自己畫的 SVG，四種表情：說話中（唸題目）、在聽、開心（記好了）、微笑（連結打不開、網路斷了、轉協助者時用，不做驚嚇表情）。

**字型**：jf open 粉圓體，用 Google Fonts 的 `Huninn`（OFL 授權），後備為微軟正黑體、蘋方。它只有 400 一種粗細，所以全頁用 400、設 `font-synthesis: none`（不讓瀏覽器假加粗），標題靠字級和顏色分層。

## 3. 農民頁畫面

畫面依後端回傳的 `stage` 和已答題目決定，重新整理或中斷後會回到原處。

主要畫面頂端都有**整體步驟列**：拍照 → 等一下 → 回答 → 簽名（做完的綠底打勾、目前的淺綠框、字 16px 以上）。答題畫面另外保留每題的粗進度條。

| 狀態 | 畫面 |
| --- | --- |
| 連結無效 | 阿伯微笑＋「這個連結打不開，不用擔心，請找協助者」 |
| `collecting`，還沒拍任何一張 | **開頭說明**：「你好」＋「我們要幫你準備土地使用同意書」；要做的事：拍土地謄本 N 張／回答幾個問題／大約 5 分鐘；有 `helper` 就顯示幫你的人（名字、電話）；主要按鈕「開始」 |
| `collecting` | **拍照**：三張提示卡（亮一點／四個角都拍到／拿穩）、拍第幾張、已拍好的縮圖 → 檢查中 → **拍照結果**（見下） |
| `extracting` | 「收到了」＋已收到的謄本縮圖＋「正在看你的謄本」（三個點慢慢變亮變暗）；每 3 秒問一次後端 |
| `reviewing`／`documented` 且還有題目沒答 | 題目照後端 `questions`，一頁一題 |
| 題目都答完 | 「謝謝你」＋**你的回答**（題目→答案）＋**接下來**（協助者核對謄本／約時間帶印章簽名）＋有電話就給「打電話給○○」按鈕（`tel:`） |
| `needs_human` | 阿伯微笑＋「協助者會跟你聯絡」＋打電話按鈕 |

第 2 題答「我自己」時，第 3 題照樣問（後端的送出條件需要 3 題都有答案）。

**第 1 題的土地卡**：地段、地號，`area_raw` 有值時加「謄本上寫：面積 X ＋`area_unit`」（沒有單位就不補單位）；`page` 對得到照片時右邊放縮圖「看照片」，點了整頁顯示照片，下面一顆大「關閉」，不用手指放大縮小。

### 拍照結果（拍完給提示）

- 左邊照片縮圖，右邊檢查清單，一個檢查一行：通過是綠色打勾＋「夠亮」「清楚」；不通過是琥珀色太陽／手的圖示＋「有點暗」「有點糊」。清單來自後端 `checks`；舊後端沒有 `checks` 時從 `reason` 推回來。
- 瀏覽器自己看照片尺寸給**小建議**（資訊圖示、灰字，不擋人）：橫的照片→「謄本是直的，手機直著拍比較好」；長邊小於 1000 像素→「靠近一點拍」。
- 能不能用只看後端的 `ok`。通過：綠色面板「這張可以用」＋「拍第 N 張」（最後一張是「謄本都拍好了」＋「繼續」）；不通過：琥珀面板＋「再拍一次」，並唸出後端的 `reason`。

### 題目由後端決定

- 用 `questions` 的順序和數量，進度條「第 n 題，共 N 題」跟著變（例如第 2 題答「別人」後多出 `L-lease`；共有土地多一題 `L-coowner`）。送出答案後用回傳的 `questions` 更新。後端沒給 `questions`，或是舊格式（選項只有代碼）時，用頁面內建的 3 題。
- `options` 的 `unsure` 一律做成下面的「我不確定」軟按鈕，不放在主要選項裡；其他選項超過 2 個就排成 2×2。
- 法律相關的題目：有 `why` 就在對話框下面加一行資訊圖示＋說明（例如「因為這筆地有好幾個地主」）；`legal: true` 在對話框上方加中性的小標籤「確認一下」（灰框，不用紅色、不用驚嘆號）。
- q1–q3 唸的句子固定用頁面內建的（對得到 Qwen3 TTS 音檔）；其他題目唸後端的 `say`，沒有音檔就用瀏覽器語音。唸回確認用選項文字：「你講，有，對嗎？」。

### 本機測試面板

只有網址是 `localhost`／`127.0.0.1` 才出現在拍照畫面最下面（虛線框、小字「測試用（只在本機出現）」）：選 C01／C02／C03，按「第 1 頁」「第 2 頁」「壞照片」直接送 `data/samples/fake-transcripts/` 的假謄本，跟相機走同一段上傳程式。

## 4. 答題流程

- 進入題目自動唸題目（第一次要先按一下畫面，瀏覽器才允許播聲音）。
- 按鈕回答：送出 → 底部面板「記好了：○○」→ 按「繼續」到下一題並唸題目。
- 語音回答：按「用講的」→ 在聽 → 聽懂就唸回「你講，○○，對嗎？」→ 按「對」或說「對」才送出。聽不懂第 1 次請他再講，第 2 次請他改按按鈕。
- 每題都有「我不確定」和左上角「回上一步」（第 1 題回到「開始回答」）。回到上一題可以改答案。
- 語音比對（`voice.js`）：先找「我不確定」類的詞；整句剛好等於某個選項文字就選它；再依題型找關鍵詞（`yesno`、`who`、`cat`、`have`：先找「沒有／沒／無／毋」再找「有」）。

## 5. 動畫

只拿來回饋「系統現在在做什麼」，不拿來裝飾。

| 時機 | 動畫 | 時間 |
| --- | --- | --- |
| 按下按鈕 | 往下沉 3px | 0.08 秒 |
| 換題 | 新畫面從右邊滑進 16px＋淡入；回上一步從左邊 | 0.3 秒 |
| 回饋面板 | 從底部升起 | 0.3 秒 |
| 進度條 | 寬度變長 | 0.5 秒 |
| 檢查照片 | 一條線在照片上慢慢上下掃 | 循環 |
| 正在看謄本 | 三個點輪流慢慢變亮 | 1.5 秒一次 |
| 在聽 | 麥克風外圈慢慢呼吸，配大字「我在聽，請說」 | 1.6 秒一次 |
| 唸回確認、照片太暗 | 大字或圖示輕輕放大出現 | 0.3 秒 |
| 完成 | 打勾一筆畫出來 | 0.4 秒 |

- 不旋轉、不搖晃、不閃爍、不彈跳。
- 每段動畫都配文字，就算動畫沒播也看得懂。
- 手機設定「減少動態效果」時，關掉全部位移與循環動畫。

## 6. 協助者頁

同一套顏色，但用一般桌面工具的密度（14–16px 字、表格），不套用高齡規則。左邊謄本照片、右邊欄位表（確認／修改／退回）、下方人工欄位、農民回答、任務、產生同意書。

後端還缺：讀取農民上傳照片的 API（`GET /api/cases/{id}/photos/{name}`）。
