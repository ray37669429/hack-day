# 法律注意事項（規則式提醒）

## 目的

從謄本資料與農民的回答，找出「簽同意書前要特別留意」的情況，
變成：給農民的固定範本問題（可聽可講）＋ 同意書「備註」欄的固定短句。程式在 `app/agents/legal.py`。

## 立場

- **提醒不是判斷**：系統只偵測情況，不下任何法律結論。
- 法條參考只是線索，字串一律以「（待法律專業確認）」結尾，只在本機管理畫面（`GET /api/cases/{id}`）顯示。
- 白皮書原列「法規判斷」不在範圍；這裡只做提醒。
- 給農民的文字是固定範本，不由 LLM 產生。
- **協助者角色已取消**：農民回答了就算處理過（包含「我不確定」），不會擋正式版，也不產生任何人工任務。
- 有風險的答案，在受影響那幾筆土地的同意書「備註」欄寫一句固定短句，讓簽約雙方看得到。
- 還沒回答的法律題（被選中要問的）會擋正式版，跟其他沒回答的題目一樣。

## 選題：只問最可能的幾題，再追問細節

法律題不能太多。agent 先算分，只問分數最高的幾題，再依答案補全細節：

1. **打分**：每條規則依案例資料算 0–100 分（可能性 × 影響），並寫出算分理由。
2. **只問前幾名**：最多問 `LEGAL_MAX_FARMER_QUESTIONS` 個注意事項（預設 2）。已回答的題目一定保留，畫面不會跳動。
3. **追問**：每題最多 1 個追問，只在答案顯示風險時出現。改答案後，追問會跟著消失。
4. **總數上限**：法律題加上追問最多 `LEGAL_MAX_TOTAL` 題（預設 3）。
5. **沒問的**：沒被選中的注意事項不問農民、不擋正式版；管理畫面會寫出分數，以及為什麼問、為什麼沒問。由資料就能看出的備註（例如共有土地）照樣寫進同意書。

法律題排在農民題目順序中的 q3 之後、「要簽幾年」之前（完整順序見 `app/agents/triage.py`）。

分數只用固定規則算。之後若改用 LLM 排序，也只能調整分數、從固定題庫挑題，不能自己產生題目文字。

## 規則

| id | 觸發條件與分數 | 農民題目 → 追問 | 參考（待法律專業確認） |
|---|---|---|---|
| `coowner` | 任一筆土地有 2 筆以上所有權登記。55 分，每多 1 位地主 +10（上限 80）；持分看不清 +10 | `L-coowner`：這筆地還有其他地主，他們知道你要簽同意書嗎？（知道／不知道／我不確定）→ 答「不知道」追問 `L-coowner-reach`：其他地主，你聯絡得到嗎？ | 民法第 818、820 條；土地法第 34 條之 1 |
| `lease` | 第 2 題答「別人」。第 3 題答承租 90、不確定或還沒答 75、託耕／輪耕／分耕 65 | `L-lease`：你跟種田的人，有沒有簽租約？（有／沒有／我不確定）→ 答「有」追問 `L-lease-375`：這份租約，是三七五租約嗎？ | 耕地三七五減租條例 |
| `unclear-share` | 權利範圍 AI 讀不到或被標「看不清」，且還沒確認。50 分 | 無（不問農民；看不清的欄位不能確認，要重拍，文件會是草稿） | 民法第 817、819 條（應有部分） |

## 備註欄的固定短句

常數定義在 `legal.py`（`REMARK_*`），由 `legal.remarks_for(case, pid)` 產生，多句用「；」串接。
只看目前有效題目的答案（例如改答「自己種」後，租約題的答案不再算）。

| 情況 | 備註 | 寫在哪幾筆 |
|---|---|---|
| 該筆土地有 2 筆以上所有權登記（共有） | 共有土地：需其他共有人同意 | 共有的那筆 |
| `L-coowner` 答「不知道」或「我不確定」 | 其他共有人尚不知情 | 共有的那筆 |
| `L-coowner-reach` 答「聯絡不到」 | 聯絡不到其他共有人 | 共有的那筆 |
| `L-lease` 答「有」（追問答「不是」） | 有耕地租約 | 全部 |
| `L-lease-375` 答「是」 | 三七五租約 | 全部 |
| `L-lease` 或 `L-lease-375` 答「我不確定」 | 租約情況未確認 | 全部 |

- 注意事項每次都從目前資料重新推出（`legal.issues(case)`），只儲存農民的回答（`case.answers`）。
  `case.legal_notes` 是舊版協助者處理紀錄，保留欄位只為相容舊資料，已不使用。
- 新增規則：在 `legal.py` 寫一個回傳 `LegalIssue | None` 的函式，加進 `RULES`；需要備註就加 `REMARK_*` 常數並寫進 `remarks_for`。

## API

- `GET /api/f/{token}`、`POST /api/f/{token}/answers`：法律題跟其他題目一樣放在 `questions`（`legal: true`、`card: null`）。
- `GET /api/cases/{id}`（本機管理）：`legal` 依分數高到低：`[{id, title, detail, reference, score, score_reason, asked, selection, question_id, answer_label, followup{question_id,text,answer_label}|null, handled}]`。`handled`：沒問農民，或農民已回答。
- 已移除：`POST /api/cases/{id}/legal/{issue_id}/resolve`（協助者處理）。
