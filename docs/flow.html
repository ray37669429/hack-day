hack-day · MVP 流程

謄本到同意書流程

農民只做三件事：拍照、回答「是／不是」、簽名。

其他工作由背景 agent 處理：檢查照片、讀謄本、比對、分題目、產文件。需要專業判斷的核對交給協助者。agent 只能提議，任何值都要人確認後才會進正式文件。

農民（手機網頁） 背景 agent 協助者（Excel 核對表） 待確認已確認退回

主流程

農民拍照、回答、簽名
背景 agent自動處理，不做決定
協助者專業核對、出文件
1
農民

拍謄本

用協助者給的專屬連結打開手機網頁，對準框框拍照。不用登入。

產物謄本照片 2 張
2
①收件 agent

當場檢查照片

太暗、反光、切到邊、少一頁，馬上請農民重拍，不等到隔天才退件。

↩ 品質不好：回到步驟 1
3
②擷取 agent

讀謄本

讀坐落與地號、面積、所有權人、統一編號、權利範圍。每個值附頁碼、原文與照片位置；看不清就留空。

產物擷取主張 全部待確認
4
③核對 agent

檢查與比對

先跑固定規則：地號格式（如 0123-0004，保留前導零）、持分加總、面積單位。再和舊清單比對，標出差異、缺漏、重複。

5
④分派 agent

這題該問誰？

本人最清楚的事給農民
專業欄位、差異、看不清給協助者
6
本人
確認 農民

回答 3 題

這是你的地嗎？誰在耕作？哪種耕作方式？一頁一題，大按鈕作答。

按鈕是／不是／我不確定
→ 按「我不確定」：自動轉給協助者
人工
確認 協助者

Excel 核對表

只看「待確認」和「有差異」的列。對照照片確認面積、持分、地號、統一編號；衝突由人選邊。

結果已確認退回
↩ 退回：請農民補拍，回到步驟 1
7
⑤文件 agent

可以出正式版嗎？

關鍵欄位全部已確認，農民的 3 題也答完了？

是產出土地清單 Excel ＋ 土地使用同意書 Word（每頁 8 列）
否只出標「草稿」的版本，附未完成清單，回到步驟 6
8
農民

紙本簽名蓋章

所有權人與耕作人在印好的同意書上簽名蓋章。

協助者

印出並安排簽名

列印正式版，聯絡農民約時間簽名；簽名欄與日期都留白。

農民端只有四個畫面

示意版面，不是最終設計。畫面中的地號為示例。

內文 ≥ 20px按鈕高 ≥ 56px圖示＋文字一頁一題只要點一下每題都有「我不確定」不用登入

每個欄位的狀態

agent 寫入的是「第 1 頁的面積看起來是多少」，不是「土地的面積」。人確認後才算數。

誰回答哪一題

由 ④ 分派 agent 依規則決定，不讓 AI 自由判斷。

問題類型例子給誰
本人最清楚的事這是你的地嗎？誰在耕作？哪種耕作方式？農民
需要專業核對面積、持分、地號、統一編號協助者
衝突或看不清謄本和舊清單不一致、照片模糊協助者
農民按「我不確定」任何題目協助者

MVP 範圍

這次做

  • 農民端手機網頁：拍照、回答 3 題
  • agent ①收件 ②擷取 ③核對 ④分派 ⑤文件
  • 協助者用 Excel 核對表
  • 產出土地清單 Excel 與同意書 Word
  • 只用遮蔽樣本或虛構資料

之後再做

  • LINE 機器人與 LINE 登入
  • 提醒 agent 與通知
  • 語音朗讀、台語語音輸入
  • 線上簽名
  • 真實謄本的個資處理流程
