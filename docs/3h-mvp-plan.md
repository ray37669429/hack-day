## 一個人怎麼搭配 Claude Code 和 Codex

一個人可以同時開兩個 AI，等於兩條線並行，但要遵守：

1. **一個 AI 一組檔案**。例如 Claude Code 做 `web/`（前端接後端），Codex 同時做 `app/agents/extract.py`（視覺 AI）。不要讓兩個 AI 改同一個檔案。
2. **共用一份規則**：兩邊都讀 `AGENTS.md`（已設定）。
3. **`app/models.py` 要改時自己決定**，改完立刻跑測試，再讓另一個 AI 重新讀。
4. **每完成一小步就跑測試、commit**：`.venv\Scripts\python -m pytest -q`。直接在 `main` 上小步提交即可，不需要開分支和 PR。
5. **卡住 15 分鐘就換方法**：改用備案或縮小範圍，不要和 AI 反覆拉扯。
6. **給 AI 的任務要短而具體**：說清楚要改哪個檔案、輸入輸出格式、完成標準（可直接用上表的「完成標準」）。

## 主要風險

| 風險 | 影響 | 對策 |
| --- | --- | --- |
| 前端接後端花太久 | 無法全程走 API 展示 | 1:40 檢查點；退回測試台模擬模式 |
| 視覺 AI 讀錯或很慢 | 擷取結果不可信 | 退回 `oracle` 引擎；所有值仍要人確認，錯誤會在核對時被抓到 |
| 手機用 http 時麥克風被擋 | 語音回答無法展示 | HTTPS 通道，或筆電 Chrome 展示 |
| 長輩講台語，國語辨識聽不懂 | 語音回答失敗 | 兩次聽不懂自動改用按鈕；台語辨識列為下一步 |
| 本機 TTS 很慢（目前一句約 60 秒） | 現場無法即時產生 | 音檔全部事先產生，現場只播放 |
| AI 工具自行擴大範圍 | 時間失控 | `AGENTS.md` 已寫明「不在 MVP 範圍不要加」 |
